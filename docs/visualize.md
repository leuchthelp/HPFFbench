# Visualize benchmark data

All results are exported as a pandas compatible [DataFrame](https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.DataFrame.html) in `JSON`.

The [components/visualize/dev_original.ipynb](https://github.com/leuchthelp/HPFFbench/blob/refactor/components/visualize/dev_original.ipynb) directory includes a simple notebook with a couple of pre-made plots using [plotly](https://plotly.com/python/)

If you wish to quickly visualize your data.
